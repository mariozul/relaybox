# Implementation Specification: Relaybox - Multi-Tenant Webhook Relay Service\n\n## 1. Core Principle: Contracts, Not Implementation\n\nThis specification defines the `struct` definitions, `interface` method signatures, sentinel error constants, and godoc documentation. It does NOT include full function implementation bodies or complete algorithms.\n\n## 2. Clean Architecture 7-Layer Component Mapping\n\n### 2.1. Entity Layer (`pkg/relaybox/domain/`)\n\n*   **`entities.go`**:\n    *   `Event` struct: `ID uuid.UUID`, `TenantID uuid.UUID`, `EventType string`, `Payload []byte`, `DedupKey string`, `CreatedAt time.Time`, `CreatedBy string`\n    *   `Subscription` struct: `ID uuid.UUID`, `TenantID uuid.UUID`, `EventType string`, `TargetURL string`, `CreatedAt time.Time`, `CreatedBy string`\n    *   `OutboxItem` struct: `ID uuid.UUID`, `EventID uuid.UUID`, `SubscriptionID uuid.UUID`, `Status OutboxStatus`, `Attempts int`, `NextAttemptAt time.Time`, `LastAttemptAt time.Time`, `Error string`\n    *   `OutboxStatus` enum type.\n*   **`interfaces.go`**:\n    *   `EventRepository` interface: `Save(ctx context.Context, event *Event, outboxItem *OutboxItem) (uuid.UUID, error)`, `FindByDedupKey(ctx context.Context. dedupKey string, tenantID uuid.UUID) (*Event, error)`, `FindByID(ctx context.Context, eventID uuid.UUID) (*Event, error)`\n    *   `SubscriptionRepository` interface: `Save(ctx context.Context, sub *Subscription) error`, `FindByID(ctx context.Context, id uuid.UUID, tenantID uuid.UUID) (*Subscription, error)`, `FindByTenantID(ctx context.Context, tenantID uuid.UUID) ([]*Subscription, error)`, `FindByEventType(ctx context.Context, eventType string) ([]*Subscription, error)`, `Delete(ctx context.Context, id uuid.UUID, tenantID uuid.UUID) error`\n    *   `OutboxRepository` interface: `FindPending(ctx context.Context, limit int) ([]*OutboxItem, error)`, `Update(ctx context.Context, item *OutboxItem) error`, `MarkDelivered(ctx context.Context, id uuid.UUID) error`, `MarkDeadLetter(ctx context.Context, id uuid.UUID, errMsg string) error`\n    *   `ContextAuthenticator` interface: `GetTenantID(ctx context.Context) (uuid.UUID, error)`\n    *   `Clock` interface: `Now() time.Time`\n*   **`errors.go`**: Define sentinel errors: `ErrNotFound`, `ErrAlreadyExists`, `ErrTenantMismatch`, `ErrInvalidInput`, `ErrUnauthorized`, `ErrInternal`, `ErrExternalService`, `ErrDeliveryPermanent`, `ErrDatabaseUnreachable`.\n\n### 2.2. Repository Interface (Defined in `pkg/relaybox/domain/interfaces.go`)\n\n*   See `EventRepository`, `SubscriptionRepository`, `OutboxRepository` above.\n\n### 2.3. Application Service Layer (`pkg/relaybox/service/`)\n\n*   **`subscription_service.go`**:\n    *   `SubscriptionService` struct with `SubscriptionRepository` and `ContextAuthenticator` dependencies.\n    *   Methods: `CreateSubscription`, `GetSubscription`, `ListSubscriptions`, `DeleteSubscription`.\n*   **`event_ingestion_service.go`**:\n    *   `EventIngestionService` struct with `EventRepository`, `SubscriptionRepository`, `ContextAuthenticator`, `Clock` dependencies.\n    *   Method: `IngestEvent(ctx context.Context, event *domain.Event, dedupKey string) (uuid.UUID, error)`.\n*   **`delivery_dispatcher.go`**:\n    *   `DeliveryDispatcher` struct with `OutboxRepository`, `SubscriptionRepository`, `SubscriberClient`, `Clock` dependencies.\n    *   Methods: `Start(ctx context.Context)`, `Stop()`, `ProcessOutboxItem(ctx context.Context, item *domain.OutboxItem) error`.\n    *   Will include logic for exponential backoff, retry attempts, and dead-lettering.\n    *   Utilizes a bounded worker pool (`semaphore` or `errgroup`).\n\n### 2.4. Infrastructure/Adapter Layer (`pkg/relaybox/infrastructure/`)\n\n*   **`persistence/`**:\n    *   **`postgres_event_repository.go`**: Implements `domain.EventRepository` using `pgx` or `database/sql`.\n        *   `Save` method will use a transaction for `events` and `outbox` table writes.\n    *   **`postgres_subscription_repository.go`**: Implements `domain.SubscriptionRepository`.\n    *   **`postgres_outbox_repository.go`**: Implements `domain.OutboxRepository`.\n*   **`auth/`**:\n    *   **`header_authenticator.go`**: Implements `domain.ContextAuthenticator` to extract `TenantID` from HTTP headers (e.g., `X-Tenant-Id`).\n*   **`clock/`**:\n    *   **`system_clock.go`**: Implements `domain.Clock` using `time.Now()`.\n*   **`httpclient/`**:\n    *   **`subscriber_client.go`**:\n        *   `SubscriberClient` struct with `http.Client` dependency.\n        *   Method: `SendEvent(ctx context.Context, targetURL string, event *domain.Event, deliveryID uuid.UUID) (*http.Response, error)`.\n        *   Ensures `ctx` propagation, OpenTelemetry tracing, and `X-Relaybox-Delivery-Id` header.\n        *   Handles `resp.Body.Close()`.\n\n### 2.5. Transport/Handler Layer (`pkg/relaybox/handler/`)\n\n*   **`event_handler.go`**:\n    *   `EventHandler` struct with `EventIngestionService`, `ContextAuthenticator` dependencies.\n    *   `PostEvent(w http.ResponseWriter, r *http.Request)`: Handles `POST /v1/events`. Decodes request, calls service, maps domain errors to HTTP status codes.\n*   **`subscription_handler.go`**:\n    *   `SubscriptionHandler` struct with `SubscriptionService`, `ContextAuthenticator` dependencies.\n    *   Methods: `CreateSubscription`, `GetSubscription`, `DeleteSubscription`, `ListSubscriptions`.\n    *   Handles `POST/GET/DELETE /v1/subscriptions` and `GET/DELETE /v1/subscriptions/{id}`.\n*   **`health_handler.go`**:\n    *   `HealthHandler` struct with `*pgxpool.Pool` or similar DB connection dependency.\n    *   `Livez(w http.ResponseWriter, r *http.Request)`: Always returns 200 OK.\n    *   `Readyz(w http.ResponseWriter, r *http.Request)`: Checks DB connectivity. Returns 503 if DB is down, else 200 OK.\n\n### 2.6. DTO / Mapper Layer (`pkg/relaybox/dto/`)\n\n*   **`event_dto.go`**: `IngestEventRequest` struct, `IngestEventResponse` struct.\n*   **`subscription_dto.go`**: `CreateSubscriptionRequest`, `SubscriptionResponse`, `ListSubscriptionsResponse` structs.\n*   Mapping functions between DTOs and `domain.Event`, `domain.Subscription`.\n\n## 3. Database Schema Migration Plan\n\n*   `migrations/YYYYMMDDHHMMSS_create_relaybox_tables.up.sql`:\n    ```sql\n    CREATE TABLE events (\n        id UUID PRIMARY KEY,\n        tenant_id UUID NOT NULL,\n        event_type TEXT NOT NULL,\n        payload JSONB NOT NULL,\n        dedup_key TEXT NOT NULL,\n        created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW(),\n        created_by TEXT NOT NULL,\n        UNIQUE (tenant_id, dedup_key)\n    );\n\n    CREATE TABLE subscriptions (\n        id UUID PRIMARY KEY,\n        tenant_id UUID NOT NULL,\n        event_type TEXT NOT NULL,\n        target_url TEXT NOT NULL,\n        created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW(),\n        created_by TEXT NOT NULL\n    );\n\n    CREATE TYPE outbox_status AS ENUM ('pending', 'processing', 'delivered', 'dead_letter');\n\n    CREATE TABLE outbox (\n        id UUID PRIMARY KEY,\n        event_id UUID NOT NULL REFERENCES events(id) ON DELETE CASCADE,\n        subscription_id UUID NOT NULL REFERENCES subscriptions(id) ON DELETE CASCADE,\n        status outbox_status NOT NULL DEFAULT 'pending',\n        attempts INT NOT NULL DEFAULT 0,\n        next_attempt_at TIMESTAMP WITH TIME ZONE NOT NULL,\n        last_attempt_at TIMESTAMP WITH TIME ZONE,\n        error TEXT,\n        created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW()\n    );\n\n    CREATE INDEX idx_outbox_pending ON outbox (next_attempt_at) WHERE status = 'pending';\n    CREATE INDEX idx_subscriptions_event_type ON subscriptions (event_type);\n    CREATE INDEX idx_events_tenant_id_dedup_key ON events (tenant_id, dedup_key);\n    ```\n*   `migrations/YYYYMMDDHHMMSS_create_relaybox_tables.down.sql`:\n    ```sql\n    DROP INDEX IF EXISTS idx_events_tenant_id_dedup_key;\n    DROP INDEX IF EXISTS idx_subscriptions_event_type;\n    DROP INDEX IF EXISTS idx_outbox_pending;\n    DROP TABLE IF EXISTS outbox;\n    DROP TYPE IF EXISTS outbox_status;\n    DROP TABLE IF EXISTS subscriptions;\n    DROP TABLE IF EXISTS events;\n    ```\n*   **Zero-Downtime Strategy**: (N/A for initial creation; assumed for future schema changes).\n\n## 4. System Observability & Telemetry Blueprint\n\n*   **Prometheus Metrics (`pkg/relaybox/metrics/`**):\n    *   `relaybox_ingestion_total_events_total{status="success|failure", event_type="<type>"}` (Counter)\n    *   `relaybox_ingestion_duration_seconds{endpoint="/v1/events"}` (Histogram)\n    *   `relaybox_delivery_total_attempts_total{status="success|transient_failure|permanent_failure|dead_letter"}` (Counter)\n    *   `relaybox_delivery_duration_seconds{event_type="<type>"}` (Histogram)\n    *   `relaybox_subscriptions_crud_total{operation="create|get|list|delete", status="success|failure"}` (Counter)\n    *   `relaybox_readyz_db_status{status="up|down"}` (Gauge)\n*   **Structured Logging (`pkg/relaybox/logger/`**):\n    *   Utilize `slog` for structured JSON logging.\n    *   Custom logger wrapper to ensure `trace_id` and `span_id` are extracted from `context.Context` and added to every log entry (RULE-OBS-01).\n    *   Standard attributes: `time`, `level`, `msg`, `trace_id`, `span_id`, `component`, `error`, `tenant_id` (where applicable).\n\n## 5. Hard Rule: PR Sizing Limit (<= 250 Declared LOC)\n\nEach subtask (mapping to a single PR) will be designed to stay within the 250 LOC declared estimate. Decomposition has considered this rule.\n\n## 6. Spec Verification Replan Budget\n\nThis is `planner_replan_cycle=0`.
