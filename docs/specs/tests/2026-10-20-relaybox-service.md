## 2. Idiomatic Go Test Patterns & Flakiness Prevention
All tests will adhere to `RULE-TEST-003` (Idiomatic Go Test Patterns & Flakiness Prevention), specifically:
- **Table-Driven Tests**: Grouping related scenarios for conciseness and clarity.
- **Deterministic Time / Clock Injection**: Avoiding `time.Now()` in domain logic by injecting time providers.
- **Fixture Teardown**: Using `t.Cleanup` or transactional rollbacks to ensure clean test state.
- **Deterministic Concurrency Discipline**: Using `sync.WaitGroup` and channels for synchronization, avoiding `time.Sleep`.
- **Mandatory `-race` Execution**: All test suites will be run with race detection enabled.
- **Coverage Gates**: Minimum 85% statement coverage on domain/service logic, 100% branch coverage on error handling.
