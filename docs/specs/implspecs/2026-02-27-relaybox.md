# ImplSpec: Relaybox Webhook Relay · PR sizing: each subtask ≤ 500 LOC (RULE-PLAN-004)

## 1. Layer Map (7-Layer Clean Architecture)
| Layer | Path | Contents |
| :--- | :--- | :--- |
| Entity | `internal/domain/` | `Event`, `Subscription`, `OutboxEntry`, `DeliveryStatus`, sentinel errors |
| Domain Service | `internal/domain/` | `IngestService` (idempotency decision), `DeliveryPolicy` (retry/dead-letter classification — pure, injected clock) |
| Use Case / Port | `internal/service/` | `IngestUseCase`, `SubscriptionUseCase`, `DispatchUseCase` interfaces |
| Repository | `internal/repository/` | `EventRepository`, `SubscriptionRepository`, `OutboxRepository` interfaces |
| Adapter | `internal/infrastructure/postgres/` | pgx implementations; `internal/infrastructure/httpclient/` egress client with OTel propagation |
| Transport | `internal/transport/http/` | handlers, router, middleware (tenant extraction, metrics, logging) |
| DTO/Mapper | `internal/transport/http/dto/` | request/response structs + mappers |

## 2. Contracts (signatures only — no bodies, RULE-IMPL 5.1)

```go
// internal/domain/event.go
type Event struct {
    ID        string
    TenantID  string
    EventType string
    Payload   []byte
    DedupKey  string
    CreatedAt time.Time // from injected Clock
    CreatedBy string
}

var (
    ErrEventDuplicate       = errors.New("event duplicate")
    ErrInvalidEventPayload  = errors.New("invalid event payload")
    ErrSubscriptionNotFound = errors.New("subscription not found")
    ErrTenantMissing        = errors.New("tenant missing")
)

// internal/domain/policy.go — pure, no time.Now()
type Clock interface{ Now() time.Time }

type DeliveryPolicy interface {
    Classify(resp *DeliveryAttempt) Action // Action: Retry(backoff) | DeadLetter | Delivered
}

// internal/repository/interfaces.go
type EventRepository interface {
    CreateWithOutbox(ctx context.Context, txFn func(ctx context.Context, tx pgx.Tx) error, e *Event, entries []*OutboxEntry) error
    FindByDedupKey(ctx context.Context, tenantID, dedupKey string) (*Event, error)
}
type SubscriptionRepository interface {
    Create(ctx, s *Subscription) error
    ListByTenant(ctx, tenantID string) ([]*Subscription, error)
    Delete(ctx, tenantID, id string) error
}
type OutboxRepository interface {
    ClaimPending(ctx context.Context, limit int) ([]*OutboxEntry, error) // SELECT ... FOR UPDATE SKIP LOCKED
    MarkDelivered(ctx, id string) error
    MarkAttempt(ctx, id string, nextAt time.Time) error
    DeadLetter(ctx, id string) error
}

// internal/service/dispatch.go
type Dispatcher interface {
    Run(ctx context.Context) error // bounded pool, honors ctx cancellation, WaitGroup shutdown
}

// internal/transport/http/handlers.go
type EventHandler interface {
    Ingest(w http.ResponseWriter, r *http.Request)   // POST /v1/events
}
type SubscriptionHandler interface {
    Create(w, r); List(w, r); Delete(w, r)             // /v1/subscriptions
}
```

## 4. Telemetry Blueprint (RULE-OBS)
- Counters: `app_ingestion_events_total{status}`, `app_delivery_attempts_total{status="delivered|failed|deadletter"}`.
- Histograms: `app_http_request_duration_seconds{method,route}`, `app_delivery_duration_seconds`.
- No unbounded labels (no tenant IDs / UUIDs in labels). `slog` JSON handler bound to ctx; `trace_id`/`span_id` auto-extracted; OTel HTTP client propagation on egress.
- `/livez` (200 always) and `/readyz` (DB ping; 503 on failure).
