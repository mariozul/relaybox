## Violation Signals
- **TC-01**: Removing the `(tenant_id, dedup_key)` unique constraint / returning a new ID on replay makes the second ingest create a second row and a different id → test fails.
- **TC-02**: Dropping the payload validation branch makes an empty `event_type` be accepted → sentinel not returned → fails.
- **TC-03**: If event insert and outbox insert are not in the same tx (or outbox write occurs after commit), killing the process after event commit loses the outbox row → post-restart delivery assertion fails.
- **TC-04**: Splitting the writes across two transactions leaves an orphaned event or outbox row on forced failure → rollback assertion fails.
- **TC-05**: Parsing `tenant_id` from the body instead of authenticated context lets a forged body set the tenant → isolation assertion fails.
- **TC-06**: Broken mapper/insert yields wrong scoping or columns → CRUD assertions fail.
- **TC-07**: If the repo's WHERE clause omits `tenant_id`, tenant B's GET returns tenant A's subscription → 404 assertion fails.
- **TC-08**: Treating 5xx as permanent (or missing backoff) dead-letters immediately → "delivered after retry" assertion fails.
- **TC-09**: Treating 4xx as retryable loops forever (no dead-letter transition) → attempt-count assertion fails.
- **TC-10**: Generating the delivery id per attempt (e.g. from attempt counter) makes headers differ across retries → equality assertion fails.
- **TC-11**: Removing the worker pool bound / mutex (or using `context.Background()` in dispatcher) triggers `-race` detector or ctx-timeout failure.
- **TC-12**: Omitting `WaitGroup.Wait()` on shutdown lets goroutines leak past cancellation → leak assertion (goroutine count) fails.
- **TC-13**: If `/readyz` doesn't ping the DB (always 200), the DB-down case returns 200 → 503 assertion fails.
- **TC-14**: Adding tenant ID as a metric label creates unbounded series; asserting the label set is exactly `{method, route, status}` fails.
- **TC-15**: Removing OTel propagation drops the `traceparent` header; removing ctx timeout lets a hanging endpoint stall past the deadline → fails.
