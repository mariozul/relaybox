# Relaybox TestSpec — locked intent

Use table-driven tests, injected clock/random, barrier/channel synchronization (no sleeps), deadline-bound I/O and t.Cleanup fixtures. PostgreSQL integration tests use real transactions. Kill/restart tests use child processes and deterministic checkpoints. No full-suite local runs.

All mandatory invariants: RULE-ARCH-01, RULE-ARCH-02, RULE-ARCH-03, RULE-DATA-01, RULE-DATA-02, RULE-DATA-03, RULE-RES-01, RULE-RES-02, RULE-RES-03, RULE-SEC-01, RULE-SEC-02, RULE-EVT-01, RULE-EVT-02, RULE-OBS-01, RULE-OBS-02, RULE-OBS-03, RULE-OBS-04. Permanent/transient acknowledgment semantics apply to outbox status, not a new broker.
