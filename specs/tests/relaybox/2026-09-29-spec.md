# Relaybox TestSpec — locked architecture baseline

Source: date-prefixed ReqSpec; approved gateway contract included. Every scenario uses Given the stated fixture, When the named operation executes, Then the following oracle holds.

Table-driven tests; injected clocks; channels/barriers and deadlines, no time.Sleep; t.Cleanup removes DB fixtures. PostgreSQL integration uses isolated schemas and real HTTP fixtures. Run only named tests with -race. Domain/service statement coverage >=85%; sentinel mapping branches 100%.
